## Context

### Original Request
CI smoke test failing with error:
```
docker: invalid reference format
Error: Process completed with exit code 125
```

### Root Cause Analysis
The `docker/metadata-action` outputs multiple tags as a multi-line string:
```
mikegemut/armorclaw:main
mikegemut/armorclaw:latest
```

When this is passed to `docker run -d --name smoke-test "$IMAGE_TAG"`, Docker interprets the entire string (including newline) as the image name, causing "invalid reference format".

### Current Code (Broken)
```yaml
- name: Run smoke test
  run: |
    IMAGE_TAG="${{ steps.meta.outputs.tags }}"
    echo "Running smoke test on $IMAGE_TAG"
    docker run -d --name smoke-test "$IMAGE_TAG"
```

### Fix Approach
Use the known `DOCKER_IMAGE:latest` tag directly since:
1. The `:latest` tag is always generated by the metadata action
2. It's available immediately after the build step
3. No parsing needed
