FAILED-UNSEAL LOCKOUT (ADDED)
-----------------------------
Fields added to SealedKeystore:
  failedAttempts:    int (in-memory counter)
  lockedUntil:       time.Time (in-memory lockout deadline)
  maxFailedAttempts: 5 (default)
  lockoutDuration:   5 minutes (default)
UnsealWithPassword now:
  1. Checks lockout before attempting verification
  2. Increments failedAttempts on wrong password
  3. Sets lockedUntil when maxFailedAttempts reached
  4. Resets counter on successful unseal
  5. Resets counter on SealPassword()
Lockout state is in-memory only (per requirement: no disk persistence for v1.0)

IDLE AUTO-SEAL
--------------
autoSealDuration: 4 hours (default, configurable via SetAutoSealDuration)
Timer resets on: ExtendPasswordSession(), resetActivityTimer()
Timer callback: sealCallback() -> SealPassword()
Vault key zeroed on auto-seal.
defaultTTL for session management: 5 minutes (from NewSealedKeystore).

RATE LIMITER
------------
Config: NewRateLimiter(5, 60*time.Second) — 5 attempts per identity per 60s
Type: Fixed-window rate limiter
Thread-safe: sync.Mutex protected
Per-identity isolation: independent windows per identity string
Window expiry: Resets after windowDuration elapses
