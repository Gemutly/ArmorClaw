## Salt Strategy
- Salt is persisted in `{dbPath}.salt` file (base64 encoded)
- Generated once on first install using crypto/rand.Reader
- Persisted across reboots to enable zero-touch operation
- 32 bytes length, stored as base64 string

## Key Derivation Hierarchy (deriveMasterKey)
1. **Priority 1**: Environment variable `ARMORCLAW_KEYSTORE_SECRET` (base64-decoded, 32 bytes)
2. **Priority 2**: Explicit secret file `{dbPath}.key` (base64-decoded, 32 bytes)
3. **Priority 3**: Container detection → Generate random 32-byte key, persist to `{dbPath}.key`
4. **Priority 4**: Native host mode → Hardware-derived key via PBKDF2-HMAC-SHA512

## Hardware-Derived Key Entropy Sources
- Machine ID (from /etc/machine-id or /var/lib/dbus/machine-id)
- DMI product UUID (from /sys/class/dmi/id/product_uuid)
- Primary MAC address
- Hostname
- OS and architecture
- CPU info

## Important Notes
- Algorithm is PBKDF2-HMAC-SHA512, NOT SHA256 as initially suggested
- Iterations are 256,000, NOT 100,000 as initially suggested
- These are SQLCipher's default parameters for maximum compatibility
- The Rust vault MUST use these exact parameters to match Go Bridge implementation
