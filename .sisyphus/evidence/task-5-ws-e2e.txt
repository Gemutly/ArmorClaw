## Architecture

EventBus → websocket.Server.Broadcast() → EventBroadcaster interface ← http.Server.BroadcastEvent()
                (adapter)                    (implemented by HTTP server)

The EventBus owns a websocket.Server. The HTTP server implements websocket.EventBroadcaster.
Main.go wires them: eventBus.SetBroadcaster(httpsServer) before eventBus.Start().
