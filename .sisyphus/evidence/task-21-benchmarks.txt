## Key Observations
====================================================================

1. Cold dispatch is the heaviest single operation (~130k–384k ns) due to
   store lookups, factory spawning, and status updates.

2. Inter-step data propagation scales linearly with payload size:
   ~10k ns for small maps → ~42k ns for large maps (4x data ≈ 4x time).

3. Template resolution (regex + string interpolation) is cheap (~6–8k ns)
   but called per-step per-input; worth monitoring as templates grow.

4. Dependency validation for 50 steps costs ~77k ns with 164 allocations —
   topological sort overhead grows with step count.

5. Event emission is allocation-heavy (~2k B for success, ~633 B for failure)
   but fast (~2k ns). The 0 allocs for success events suggests sync pooling.

6. EventBus serialization round-trip (~7.6–10.7 µs) is dominated by JSON
   marshal/unmarshal; the wrapper adds ~1.2 µs overhead.
