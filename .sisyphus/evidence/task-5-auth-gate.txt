=== SUMMARY ===
Auth gate status: NOT ACTIVE

SECURITY FINDING:
The admin_token in config.toml is NOT being enforced by the RPC middleware.
ALL methods are callable WITHOUT authentication or with WRONG authentication.
The "token" param is accepted but never validated against admin_token.

This means:
- bridge.status exposes TLS fingerprint, cert details
- health.check exposes keystore state, Matrix connection status
- All 16 new RPCs are callable without auth
- The Unix socket is the only protection layer (root-only access)

RISK ASSESSMENT: LOW-MEDIUM
- Socket is root-only (requires SSH root access to VPS)
- No remote RPC exposure without additional config
- However, any process running as root on VPS has full access
- admin_token config exists but middleware does not enforce it

RECOMMENDATION: Auth middleware needs to be connected to the RPC handler chain.
The token parameter is consumed by handlers but never validated against admin_token.
