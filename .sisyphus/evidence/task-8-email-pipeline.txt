## Finding: outboxStore wiring gap (not a config issue)

The `outboxStore` field on `rpc.Server` was NEVER wired up:
- NOT in rpc.Config struct
- NOT set in rpc.New() constructor  
- No setter method (SetOutboxStore) existed
- Never initialized in cmd/bridge/main.go

The email.NewOutboxStore() function existed but was never called.

## Code Changes Made

1. bridge/pkg/rpc/server.go:
   - Added `OutboxStore OutboxStoreReader` field to Config struct
   - Wired `s.outboxStore = cfg.OutboxStore` in New()

2. bridge/pkg/config/config.go:
   - Added EmailConfig struct with OutboxDBPath field
   - Added `Email EmailConfig` to Config struct

3. bridge/cmd/bridge/main.go:
   - Added outbox store initialization before rpc.New():
     - Resolves DB path (defaults to <keystore_dir>/email-outbox.db)
     - Creates email.NewOutboxStore(outboxDBPath)
     - Gracefully degrades if init fails (warning log, RPCs return "not configured")
