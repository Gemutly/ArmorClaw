### BlindFill Flow
```
1. Agent requests secret (e.g., "user.email")
2. Bridge masks as {{VAULT:email:sha256hash}}
3. Agent sees placeholder only
4. Playwright injection swaps placeholder → real value
5. Browser form receives real value (agent never sees it)
```

### Matrix E2EE Flow
```
1. ArmorChat calls verifyDevice()
2. Matrix Conduit verifies device identity
3. E2EE keys exchanged
4. Secure channel established
5. Messages encrypted end-to-end
```
