Scope Confirmed
---------------

MUST NOT:
- Conditionals (e.g., {{secret:if condition}})
- Loops (e.g., {{secret:for item}})
- Nested placeholders (e.g., {{secret:{{other}}}})
- String interpolation or manipulation
- Fallback values or defaults

MUST:
- Flat secret name lookups
- Exact string matching
- Simple replacement semantics
